# baozi-store
This is a university project about a bread shop.

## Objective
The Baozi Store aims to demonstrate its basic management of customers, products and orders.

## Technologies
* **Language:** Java(21)
* **Database:** MySQL
* **Dependency management:** Maven

## Endpoints
* GET/customers - List all customers.
* GET/customers/{id} - Get details about a specific customer.
* POST/customers - Register a new customer.
* PUT/customers/{id} - Update the data for a specific customer.
* DELETE/customers/{id} - Remove a specific customer.
* GET/products - List all products.
* GET/products/{id} - Get details about a specific product.
* POST/products - Register a new product.
* PUT/products/{id} - Update the data for a specific product.
* DELETE/product/{id} - Remove a specific product.
* GET/orders - List all orders.
* GET/orders/{id} - Get details about a specific order.
* POST/orders - Register a new order.
* PUT/orders/{id} - Update the data for a specific order.
* DELETE/orders/{id} - Remove a specific order.
